# Explaining a key

Changes nothing. For "what does Hyper+K do":
1. `pilot key hyper+k` (or `hyper+shift+n`, or a plain combo as `leftAlt+h`): the action, whether the preset gave it
   or it was set by hand, whether it is switched off, and any macOS shortcut a plain combo clashes with.
2. A plain combo that does nothing may be one macOS takes: `pilot conflicts` lists them.
3. Answer in one or two lines: the key, what it runs, where it came from. Name the fix only when asked.
